## خارطة المراحل المقترحة (قسم 56)
1. Design System (ألوان/خط/Header/Footer/بطاقات/أزرار/حقول/جداول/Modals/حالات فارغة)
2. الموقع العام (الرئيسية، التعريفية، النماذج، الأدوات، تواصل، التقويم، روابط)
3. Shell البوابة الداخلية (Header/Navigation/بحث/تقويم/حساب/مساعدة/Footer)
4. لوحة الإدارة (Executive Dashboard - راجع قسم 11: 4-6 KPI فقط، لا جداول طويلة)
5. الحذف والإضافة (تبويب مستقل - **منجَز جزئيًا اليوم**)
6. لوحة الإرشاد + متابعة الإرشاد + متابعة الحالات (مركز Case Management جديد)
7. الخدمات الأكاديمية
8. المنسوبين + رفع الملفات (**مركز رفع موحَّد - منجَز جزئيًا اليوم**)
9. التقارير (مركز تقارير سريع) + المصول التشغيلي (بدل "تجربة الصفحات")
10. Responsive + QA + Accessibility

## قرارات دمج/إزالة تكرار مهمة (قسم 47، 53)
- بحث المرشد يُدمَج داخل "متابعة حالة الإرشاد" (لا صفحة مستقلة).
- رفع الملفات: مكان واحد فقط لكل عمليات الرفع.
- "تجربة الصفحات" تُعاد تسميتها "الوصول التشغيلي" مع Banner توضيحي عند العمل بصلاحية أخرى.
- دليل التشغيل ينتقل خارج قائمة الحساب إلى مركز مساعدة مستقل.
- الاسم الموحَّد للوظيفة: "بوابة وحدة الإرشاد الأكاديمي والخريجين" / "كلية إدارة الأعمال - جامعة الطائف".

## قاعدة ذهبية
لا تُنشأ صفحة جديدة إذا أمكن دمج الوظيفة في صفحة قائمة. لا تكرار للوظائف
في أكثر من مكان. الأولوية لتجربة Desktop 1920×1080 احترافية مع Responsive كامل.
