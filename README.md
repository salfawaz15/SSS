# بوابة وحدة الإرشاد الأكاديمي والخريجين - كلية إدارة الأعمال - جامعة الطائف

تطبيق ويب Flutter/Firebase لإدارة عمليات الإرشاد الأكاديمي: الجداول الدراسية، توزيع الأعباء، متابعة حالات الإرشاد، التقارير، وحسابات المستخدمين.

- Firebase Hosting: https://sss-advising-tu.web.app
- دورة النشر المعتادة: `flutter analyze` → `flutter build web --release --pwa-strategy=none` → `firebase deploy --only hosting` (وقواعد Firestore عبر `firebase deploy --only firestore:rules` عند تغييرها).

## سجل الإنجاز

### صفحة متابعة حالات الإرشاد (متابعة حالات الإرشاد) - قلب المشروع
- إنشاء الصفحة كاملة: رفع تقارير المنظومة الجامعية (بيانات الطلبة، مرشدون بلا طلاب، طلاب على غير مرشدهم، الحالة الصحية، تقرير المطابقة الرسمي)، وتحليل تلقائي لعدة حالات:
  - طلاب بلا مرشد، طلاب لدى مرشد من قسم آخر، مرشدون معفون لديهم طلاب، مرشدون بلا طلاب، مرشدون محمّلون فوق طاقتهم مقابل النصيب العادل، طلاب في نطاق مخاطر (المعدل التراكمي)، حالات صحية غير مسندة لأمين القسم.
  - تقرير "إعادة التوزيع" يسمّي الطلاب المطلوب نقلهم مع المرشد المستقبِل الموصى به.
  - تسوية بين التقرير الرسمي (طلاب على غير مرشدهم) والانتدابات المصحَّحة يدويًا في ملف هيئة التدريس (حالتا حنان عامر وطارق حلمي).
  - ترتيب موحّد في كل الجداول والتقارير: شطر ← قسم ← عضو.
  - بطاقات إحصائية بتصميم شبكي 4 في كل صف.
  - رفع موحّد لكلا الشطرين لكل التقارير الخمسة (يُفرز داخليًا تلقائيًا عبر عمود الجنس إن وُجد).

### الجداول الدراسية (الحويّة) وصفحات أخرى
- إصلاح تقارير Microsoft Forms: إزالة أرقام الخطة، إعادة تصميم الشريط لصف واحد، دعم المقررات الاختيارية المشتركة بين أقسام متعددة.
- رفع "مواد خارج الكلية" عبر ملف Word، ومطابقتها تلقائيًا مع كتالوج المقررات.
- إصلاح ترتيب أعمدة PDF (كان معكوسًا خطأً)، إخفاء "نوع الخطة" دائمًا، إخفاء عمود "القسم" تلقائيًا عند تفعيل فلتر قسم محدد، توسيط كل خلايا الجداول.
- إصلاح جذري: مطابقة أسماء الأقسام غير الدقيقة (فراغات/همزات) في `college_roster_parser_service.dart`.
- إصلاح: خانة "الشطر" الفارغة كانت تُقصي أعضاء هيئة التدريس من فلاتر الشطر المحدد.
- إضافة عمود "العبء الدراسي" الفعلي (من الجداول المجدولة) في صفحة الهيئة التدريسية، بجانب "عبء الإرشاد".
- إضافة مربعات بحث في الجداول الرئيسية (اختيار المقرر، حالات الإرشاد).
- إضافة أزرار "تفريغ البيانات" بجانب كل زر رفع في التطبيق لتسهيل إعادة الاختبار.

## ملاحظات تقنية دائمة
- أي رفع ملف جديد: افتراضيًا رفعة واحدة موحّدة للشطرين تُفرز داخليًا (استثناء حالي: جداول المقررات/الحويّة تبقى منفصلة لحين تأكيد إمكانية سحب تقرير موحّد من الجامعة).
- `pw.TableHelper.fromTextArray`: ترتيب الأعمدة في المصفوفة هو ترتيب بكسل LTR حرفي، ولا ينعكس تلقائيًا مع `textDirection: rtl`.
- تحليل ملفات Word: مطابقة الأعمدة بأسماء الترويسة (Header) وليس بالفهرس الثابت.
