# بوابة وحدة الإرشاد الأكاديمي والخريجين - كلية إدارة الأعمال - جامعة الطائف

تطبيق ويب Flutter/Firebase لإدارة عمليات الإرشاد الأكاديمي: الجداول الدراسية، توزيع الأعباء، متابعة حالات الإرشاد، التقارير، وحسابات المستخدمين.

- Firebase Hosting: https://sss-advising-tu.web.app
- دورة النشر المعتادة: `flutter analyze` → `flutter build web --release --pwa-strategy=none` → `firebase deploy --only hosting` (وقواعد Firestore عبر `firebase deploy --only firestore:rules` عند تغييرها).

- **PDF الشامل** (`advising_schedule_pdf_service.dart`, `buildAll`): كان يبني صفحة/صفحات كاملة لكل قسم (بكل أيامه) ثم ينتقل للقسم التالي؛ الآن يبني صفحة لكل **يوم** (الأحد فالاثنين فالثلاثاء)، وداخل كل يوم قسمًا فرعيًا مرتَّبًا لكل (قسم × شطر) له بيانات بذلك اليوم - بطلب سليمان صراحةً ليطابق ترتيب الجداول الرسمية المعتادة.

- **محاولة قائمة منسدلة (Data Validation) داخل ملف الإكسل فشلت**: جُرِّبت لعمودي "نصاب الإرشاد" و"النصاب التدريسي" لمنع أخطاء الكتابة اليدوية، لكن تبيّن أنها تكسر قراءة الملف بمكتبة `excel` (v4.0.6) المستخدَمة فعليًا بالموقع (رسالة "تعذّر قراءة الملف" عند الرفع) - أُزيلت تمامًا وأُعيد بناء الملف نظيفًا. **البديل المعتمَد**: تحقّق داخل التطبيق نفسه عند الرفع (`_invalidQuotaValues` في `college_roster_admin_screen.dart`) يعرض تنبيهًا بأي قيمة غير معروفة بالعمودين ضمن حوار تأكيد الاعتماد، مقابل قوائم القيم الصحيحة الموثَّقة في `AdvisingLoadRules.validAdvisingQuotaValues`/`TeachingLoadRegulation.validQuotaReductionValues`.
- **تنظيف مجلد "المرفقات/أعضاء هيئة التدريس"**: حذف كل النسخ الاحتياطية والملفات القديمة غير المتتبَّعة في git (كانت تسبب لخبطة في تحديد أي ملف يُرفَع) - أبقي فقط الملف الرسمي الحالي.

### إصلاح حساب نصاب التدريس المخفَّض وحساب الساعات الزائدة الحقيقية (2026-08-08)
